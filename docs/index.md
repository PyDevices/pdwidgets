# pdwidgets

Documentation for the **pdwidgets** widget toolkit — a pure-Python pydisplay add-on for building GUIs on microcontrollers and desktop Python. There is no native C extension; it is published to TestPyPI and micropython-lib / MIP.

pdwidgets depends on the PyDevices packages `eventsys`, `pygraphics`, and
`multimer`, plus `palettes` for theming. The pydisplay repo supplies examples,
tutorials, and the browser gallery.
