# pdwidgets

Documentation for the **pdwidgets** widget toolkit — a pure-Python PyDevices add-on for building GUIs on microcontrollers and desktop Python. There is no native C extension; it is published to TestPyPI and MIP package index.

pdwidgets depends on the PyDevices packages `eventsys`, `pygraphics`, and
`multimer`, plus `palettes` for theming. The pydevices-examples repo supplies examples,
tutorials, and the browser gallery.
